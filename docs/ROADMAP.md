# 路线图

## 近期

- 增加推荐结果分享链接，方便两个人复现同一组起点和参数。
- 增加路线异常过滤，例如公交含打车、步行过长、换乘过多。
- 支持只筛选有特定音游机种的店铺，需要接入更细的机台数据源。
- 增加“收藏/排除店铺”的本地偏好。

## 中期

- 支持更多城市，优先补全成渝杭宁武汉等音游活跃城市。
- 做成可部署版本：后端隐藏高德 Web 服务 key，前端使用受域名限制的高德 JS key。
- 增加批量路线任务队列，避免多人使用时触发高德 QPS 限制。
- 增加数据更新脚本，自动抓取城市页并生成变更报告。

## 长期

- 多人约勤，不限两个人。
- 按营业状态、营业时间、人均消费和机台质量综合推荐。
- 移动端分享体验优化。
